# Sprint 01 Plan

## Sprint Goal
Establish the site foundation: structure, layout system, and core pages with placeholders.

## Committed Backlog
- Confirm static site stack (e.g., Astro, Eleventy, or plain HTML/CSS).
- Define site map and navigation structure.
- Create base layout and routing.
- Set up typography and color system.
- Add responsive grid and layout utilities.
- Implement header, footer, and global styles.

## Tasks
- Create page skeletons for Home, Publications, Projects, Contact.
- Implement shared layout component.
- Add basic CSS variables and type scale.
- Add mobile-first layout tests.

## Demo Checklist
- Navigation works between pages.
- Layout adapts to mobile and desktop.
- Placeholder content visible on each page.
