# Agile Planning

This folder contains the planning artifacts for building the personal professional website.

## Structure
- `vision.md` — product vision and goals
- `backlog.md` — prioritized backlog of user stories and tasks
- `roadmap.md` — release phases and milestones
- `definition-of-done.md` — quality and acceptance criteria
- `sprints/` — sprint plans and reviews

## Working Agreements
- Two‑week sprints.
- Each sprint has a goal, committed backlog, and a demo checklist.
- Keep tasks small (<= 1–2 days).
- Update `backlog.md` and current sprint file after each change.
